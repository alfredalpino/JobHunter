JobHunter — worldwide jobs (no coding needed)

1) Run once:  ./setup-once.sh
2) Optional:  ./.venv/bin/pip install python-jobspy
3) Open:      double-click "Open JobHunter.command"   OR   ./run.sh
4) Upload CV → pick region → Analyze → Find jobs
5) Edit easy settings anytime: aspirants/<id>/preferences.yaml
   Template: config/preferences.example.yaml

CLI:
  ./run.sh easy --resume your.pdf --name "Your Name" --region bangalore
  ./run.sh easy-hunt --id your-name
  ./run.sh regions

Only jobs from the last 1–2 weeks are kept. No auto-apply.
